# Third-party licences to keep in mind

Most dependencies use permissive licences (MIT, Apache-2.0, BSD, ISC). These ones need attention.

| Component | Licence | Where | What it means |
|---|---|---|---|
| `@imgly/background-removal` | **AGPL-3.0** | Optional "Remove background" on the design screen (browser only, loaded on demand) | If the app is offered publicly, its **complete source code must be made available** to users under the AGPL. That's fine for an open academic project. **Before a closed-source commercial launch, either buy IMG.LY's commercial licence or remove/replace this feature** (e.g. with a server-side model behind a provider interface). The feature also downloads its model (~40 MB) from IMG.LY's CDN on first use. |
| Fonts in `public/fonts/` | SIL OFL 1.1 / Apache-2.0 | Text layers, print files | Embedding in print files is allowed. Keep the licence files next to the fonts, and don't sell the fonts on their own. |
| `nodemailer` | MIT-0 | Worker: sends customer emails over SMTP | Permissive; no action needed. |
| `@gradio/client` | ISC | Worker only: calls the try-on Spaces | Permissive; no action needed. |
| Try-on models on Hugging Face Spaces (IDM-VTON, OOTDiffusion, Leffa) | Per Space/model (research licences, some **non-commercial**: IDM-VTON is CC BY-NC-SA 4.0) | Worker, only when `TRYON_PROVIDER=huggingface` | We call public demo Spaces; we don't ship the models. Check each model's licence and the Space's terms **before any commercial use**, and replace them with a licensed or self-hosted model if needed. |
| Local planner (`PLANNER_PROVIDER=local` or `PLANNER_FALLBACK=local`, `pnpm llm:setup`) | Qwen3.5-4B weights (`unsloth/Qwen3.5-4B-GGUF`): Apache-2.0; llama.cpp (`brew install llama.cpp`): MIT | Worker only | Downloaded to the worker machine, never committed or shipped. Permissive; commercial use allowed. |
| Local try-on models (`TRYON_PROVIDER=local`, `pnpm tryon:setup`) | CatVTON try-on weights: **CC BY-NC-SA 4.0 (non-commercial)**; Stable Diffusion 1.5 inpainting: CreativeML OpenRAIL-M (use restrictions); LCM-LoRA (`latent-consistency/lcm-lora-sdv1-5`): CreativeML Open RAIL++-M (use restrictions); sd-vae-ft-mse: MIT | Worker, only when `TRYON_PROVIDER=local` | Downloaded to the worker machine, never committed or shipped. Our own code (`worker/local-tryon/catvton_server.py`) follows the CatVTON paper's method and doesn't copy its source. **Before any commercial launch**, license the weights from the authors or replace the model. |
| Local 3D model (`MODEL3D_PROVIDER=local`, `pnpm model3d:setup`) | TripoSR code and weights (`stabilityai/TripoSR`): MIT; DINO ViT-B/16 config (`facebook/dino-vitb16`): Apache-2.0; PyMCubes: BSD-3-Clause; trimesh: MIT | Worker, only when `MODEL3D_PROVIDER=local` | Downloaded to the worker machine, never committed or shipped. Permissive; commercial use allowed. |
| `@google/model-viewer` / `three` | Apache-2.0 / MIT | Browser: the 3D view ([3d-view.md](3d-view.md)) | Permissive; no action needed. |
| `onnxruntime-web` | MIT | Browser: runs the on-device vision models ([live-try-on.md](live-try-on.md)) | Permissive; no action needed. |
| On-device vision models: MoveNet Lightning (`Xenova/movenet-singlepose-lightning`), selfie segmentation (`onnx-community/mediapipe_selfie_segmentation`), YuNet (`opencv/face_detection_yunet`), body parts (`senty-au/selfie_multiclass_256x256-ONNX`: Google's MediaPipe selfie multiclass model converted to ONNX) | Apache-2.0, Apache-2.0, MIT, Apache-2.0 | Served from `public/vision/` (downloaded by `pnpm vision:fetch`, not committed) | Permissive; commercial use allowed. Keep their licence notices if the files are redistributed. |
| `sharp` / libvips | Apache-2.0 / LGPL-3.0 | Server image processing | LGPL is satisfied by dynamic linking via the prebuilt binaries. No action needed. |
| Test people in `tests/fixtures/tryon-*.jpg` | FLUX.1 schnell outputs (model: Apache-2.0) | Try-on tests | AI-generated people who don't exist; free to use in tests and screenshots. |

They're samples, not photos of real garments: replace them with real product photos before launch. |
